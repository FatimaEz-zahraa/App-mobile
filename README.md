# 🏃‍♂️ Sport Tracking Mobile App

A mobile application for real-time running tracking and performance analysis.
The app allows users to track their running activities using GPS and analyze detailed statistics such as distance, speed, time, and calories burned.

## 🚀 Technologies

* React Native
* NestJS
* PostgreSQL
* REST API

## 📱 Features

* Real-time GPS tracking
* Running statistics (distance, speed, duration, calories)
* Activity history
* Performance analysis
* User authentication

## 🏗️ Project Architecture

Frontend:

* React Native

Backend:

* NestJS

Database:

* PostgreSQL

## ⚙️ Installation

### Clone the repository

```bash
git clone (https://github.com/FatimaEz-zahraa/App-mobile.git)
```

### Frontend

```bash
cd mobile
npm install
npm start
```

### Backend

```bash
cd backend
npm install
npm run start
```
